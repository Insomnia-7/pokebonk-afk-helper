# PokéBonk 无尽挂机助手

可配置的浏览器用户脚本。当前发布 **2.1.0**，已核对官网 **0.8.55 / 0.8.57**。

[安装脚本](https://raw.githubusercontent.com/Insomnia-7/pokebonk-afk-helper/main/pokebonk-afk.user.js) · [反馈问题](https://github.com/Insomnia-7/pokebonk-afk-helper/issues)

支持自动选择祝福/升级、自动寻球、免费球不限预算、普通球预算、异色优先捕捉、永久收录与局内助手分开处理，以及道具/属性/助手名单设置。首次运行默认暂停，金额留空。

文件：pokebonk-afk.user.js。版本 2.1.0。

此版包含自动选择、寻找精灵球、免费球拾取、普通球预算、异色捕捉、永久收录目标捕捉、局内助手取舍，以及道具和属性优先级设置。

## 安装与启动

1. 在玩 PokéBonk 的浏览器安装 Tampermonkey（油猴）：https://www.tampermonkey.net/ 。
2. 油猴 → 新建脚本，删除默认内容，把 pokebonk-afk.user.js 全部粘贴进去，保存。若安装过旧版，先停用旧版，避免同时操作。
3. 油猴要求用户脚本权限时，在扩展设置中开启“允许用户脚本”；若浏览器没有此开关，按油猴官方说明开启开发者模式：https://www.tampermonkey.net/faq.php?q=Q209 。
4. 下次打开游戏官网，会出现左侧“PokéBonk 无尽挂机助手”。首次默认暂停。点“设置”，按自己的偏好填写，保存后点“启动”，或按 F8。
5. 已在进行的一局不必为安装而刷新：可以复制整个脚本，在游戏浏览器 F12 → Console（控制台）粘贴并运行，关闭控制台回到游戏。如果游戏处于暂停页，手动点一次“继续”。临时运行不会在刷新后保留脚本本身；油猴安装适合长期使用。

F8 随时暂停/启动，暂停会松开脚本按住的移动键。设置界面打开期间暂停脚本操作，游戏本身仍由游戏控制。设置保存在本浏览器；之后会沿用上次的启用状态。

## 普通球预算：全部由玩家填写

三个金额字段初始都为空，单位是游戏内宝可币 ₽：

| 字段 | 含义 |
| --- | --- |
| 单球最高价格 | 下一颗普通球超过此价格时不买 |
| 购买后至少剩余 | 买完后余额低于此数字时不买 |
| 本局球费总上限 | 累计球费加下一颗价格超过上限时不买 |

全部留空＝不自动买普通球。至少填一项才启用普通球购买；其他空白字段不设限制。填 0 与留空不同。

免费超级球和游戏赠送的免费红球不受这三个字段限制，也不占用球费上限。被诅咒的球不属于普通免费球，不会自动打开。

球费从脚本连接当前对局起计数，连接之后手动开的付费普通球也计入。脚本不会把本局开始后、连接之前已花的钱追算进去。切换新对局后重新计数；迁移地图不重置本局额度。

## 寻球与移动

- 读取当前游戏地图上的普通球、免费球位置，按优先级选目标。
- 异色目标优先，其次是需要保留的虚弱助手、其他永久收录目标，再处理免费球和符合预算的普通球。
- 根据地形高度、坡度、碰撞物规划路线，通过游戏现有移动键行走。
- 接近目标后读取实际交互对象，再按 E；不会隔空开球或直接增加道具。
- 可以选择绕开当前已知的持续伤害地面。
- 卡住会尝试跳跃、重算路线；无法到达的球暂时跳过后再试。
- 当前实现不自动迁移地图。高台、复杂跳台、动态障碍物可能导致绕路或跳过；寻路不保证到达每颗球。

关闭“自动寻路”后，自动选卡仍可使用；符合条件且已经在身边的球和捕捉目标仍可交互。

## 捕捉：永久收录和局内助手分开

### 红色精灵球／大师球对应的捕捉流程

当游戏把目标交给永久捕捉流程时，脚本会接近、等待虚弱并投球；异色和经典异色始终优先。普通的可永久收录目标可以在设置中关闭。

脚本使用游戏原有投球流程。是否使用大师球、是否保证成功、是否可永久收录，由游戏自身决定；原流程可能消耗已有的大师球道具。它不会把不可捕捉的普通首领强行变为可捕捉对象。

### 绿色友友球：只在本局战斗的助手

对虚弱的 Alpha 头目，按以下顺序判断：

1. 异色保护优先，不按放弃名单处理异色。
2. “放弃助手名单”中的非异色头目不保留。
3. “优先保留助手名单”中的头目优先保留。
4. 其他目标按所选模式处理：按辅助属性择优、只收名单，或只取免费球掉落。

默认按辅助属性择优，优先幸运和直接伤害。助手辅助效果依据第一属性判断；玩家可调整助手属性排序。队伍有空位时接收，满队时与现有普通助手比较。自动替换时不释放异色随从，也不主动替换已列入保留名单的旧助手；如果没有可替换位置，新助手不入队。

保留／放弃名单支持每行一个中文名称或图鉴编号，例如“皮皮”或“35”。不预填指定宝可梦，由玩家决定。

### 超级球掉落发生在捕捉之前

已核对当前客户端：虚弱头目按 G 放弃捕捉，会走击败头目并掉落免费超级球的奖励流程；捕捉后再从队伍释放，没有这份奖励。

因此，脚本会先判断不需要的头目，再按 G，随后寻找其掉落球。它不会先捕捉再放生并声称能换球。

### 抓到异色后出现“随从替换”

此时图鉴／异色收集已经由游戏记录，弹窗选择的是哪只随从在本局跟随。可选按辅助属性择优、保留旧随从或使用新随从；默认按辅助属性择优。

## 道具与属性偏好

“属性优先级”每行一个属性，从上往下排序。默认幸运＞伤害，再考虑其他攻击、生存和收益属性。同类数值更高的优先，随后比较品质；没有匹配则按品质兜底，仍相同选靠左的选项。

- 优先道具名单：优先于属性排序，越靠上越先选。
- 不想要的道具：多选时排除，单件时卖出，所有候选都被排除时选择“都不要”换宝可币。
- 道具名称或道具 ID 都可填写；设置中的道具目录可以搜索并加入名单。
- 没有指定名称的道具，按实际效果描述排序，避免把“幸运蛋”名称中的幸运误当成幸运属性。
- 升级卡、祝福和道具支持连续处理。升级时不会主动使用重抽、放逐或跳过次数。

玩家可以分别设置“升级／道具属性顺序”和“助手辅助属性顺序”，两者互不覆盖。此排序不等于自动计算每种流派的最优搭配。

## 其他开关与范围

- 终极技就绪自动释放，可以关闭。
- 默认自动拒绝契约，可以关闭后手动决定。
- 商店、赌博、祭坛交换、忘招、融合、迁移传送门、放弃当前对局、重新开始和未知弹窗不自动操作。
- 未识别页面会显示“待手动”。游戏暂停、死亡或进入菜单时停止移动，不自动开始新局。
- 自动移动和捕捉限于生存／无尽模式。
- 保持电脑唤醒、游戏页面打开；建议标签页可见。电脑睡眠、浏览器冻结标签页或游戏自身暂停时，脚本不能让游戏继续推进。

## 适配与验证

适配已核对的官网客户端：0.8.55（mvob1c8t）及 0.8.57（mvpdimhl）。交付前已同步核对新版捕捉、队伍、开球和数据入口。此版依赖当前客户端的数据结构，其他构建会停止连接寻路／捕捉，已识别的普通选卡逻辑仍可使用。

使用官网原始模块的 App 实例入口读取本局状态，通过已有键盘与按钮操作；只包裹界面方法记录候选和实际开球消费，不改伤害、血量、金币、概率、存档或后端请求。

本地离线验证覆盖：地形避障、镜头方向换算、预算边界、预算空白时不买普通球、免费球不占预算、移动到球后交互、异色永久捕捉与友友球分支、普通首领不误捕、虚弱头目放弃后拾球、官网实际助手替换与异色随从选择界面、道具优先/排除及单件卖出、F8 松键。

尚未在你的真实账号或正在进行的对局中实测，也没有完成通宵挂机验证。初次使用应先观察一轮寻球与选卡是否与实际界面一致。


## 自动更新与异常提示停机

脚本设置了 GitHub 固定发布地址的 @updateURL 与 @downloadURL。通过油猴安装后，由油猴按其更新设置检查并安装仓库中版本号更高的发布；控制台临时运行不具备油猴的安装更新机制。未来维护者仍需要核对新游戏版本并发布新的脚本，更新地址不会自动修复代码。

脚本每 5 分钟检查一次游戏官网公开的 version.json，也可点“检查游戏更新”。发现官网新版只提示，不刷新当前对局，以免刷新导致本局结束。未适配游戏构建不连接自动寻路和捕捉。

如果游戏返回账号封禁状态，或页面明确显示账号限制、反作弊警告、未通过服务器校验等提示，停止全部脚本操作并松开移动键，保留游戏原有通知处理；不自动确认或关闭警告。暂停会锁定，需手动核对后重新打开页面再决定是否启用。

这属于可见提示和明确账号状态的响应，不是检测服务器内部反作弊，也不包含规避检测。没有提示不表示脚本获游戏官方许可，不能保证账号或排行榜成绩不受影响。
